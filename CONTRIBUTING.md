# Contributing

Issues and pull requests are welcome for clearer explanations, reproducible synthetic examples, or official-documentation corrections.

1. Open an issue describing the concept, source of truth, and why it matters.
2. Use fictitious customers, IDs, policies and sample outputs only. No PII, private assessment contents, real logs, support cases, or confidential employer/client information.
3. Link official Salesforce docs for product-specific facts and explicitly date version-dependent claims.
4. Mark SQL and Agent Script conceptual unless executed and validated in the named environment and version.
5. Include before/after tests for changes to fixture logic or metrics.
6. Keep diagrams accessible in Markdown; avoid uploading private screenshots.

This project is independent and not endorsed by Salesforce.
